# Homebrew tap for Cadence

[Cadence](https://cadencevoice.ai) keeps every coding agent in one inbox, with on-device dictation. macOS 13+ on Apple Silicon.

```sh
brew install --cask maxprehoda/tap/cadence
```

Cadence updates itself from inside the app. To upgrade through Homebrew instead, run `brew upgrade --cask --greedy cadence`.
